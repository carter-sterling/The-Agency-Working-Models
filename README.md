# The-Agency-Working-Models
Веб-платформа и лаборатория количественных исследований Carter &amp; Sterling. Объединяет сайт агентства и вычислительные модели GNU Octave: спектральную фильтрацию HFT (FFT), ПИД-контроль ликвидности казначейства, разреженную оптимизацию портфелей (QP) и термокинематику робототехники.
