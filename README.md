## 🧮 Модули вычислительного ядра (GNU Octave Engine)

Все алгоритмы оптимизированы для выполнения в базовой среде **GNU Octave** без необходимости установки сторонних зависимостей.

### 1. Automated Treasury Liquidity Management (`Automated_Liquidity_Management.m`)

* **Методология:** Дискретный ПИД-регулятор (Discrete PID Controller), замкнутый контур обратной связи, метод Эйлера.
* **Применение:** Автоматическое поддержание целевого остатка ликвидности ($10M Target Liquidity Shock), расчет управляющего импульса кредитных линий и демпфирование финансовых колебаний казначейства.

### 2. High-Frequency Market Microstructure & Signal Detection (`Algorithmic_High_Frequency_Trading.m`)

* **Методология:** Быстрое преобразование Фурье (FFT), спектральная фильтрация в частотной области, обратное IFFT, дифференциальные триггеры.
* **Применение:** Выделение доминирующих макро-циклов из высокочастотного тикового потока, устранение микроструктурного шума (Bid-Ask bounce) без фазовой задержки (Zero-lag) и детекция экстремумов тренда.

### 3. High-Dimensional Portfolio Optimization (`Quantum_Portfolio_Optimization.m`)

* **Методология:** Квадратичное программирование (Sparse QP), условия Каруша — Куна — Таккера (KKT), регуляризация Тихонова (Ridge).
* **Применение:** Построение границы эффективности Марковица (Markowitz Efficient Frontier) для 200+ активов на базе разреженных ковариационных матриц и расчет портфеля касания (Tangency Portfolio / Max Sharpe Ratio).

### 4. Macroeconomic Modeling (`Macroeconomic_DSGE.m`)

* **Методология:** Динамическое стохастическое общее равновесие (DSGE).
* **Применение:** Моделирование трансмиссионных шоков денежно-кредитной политики, процентных ставок и инфляционных ожиданий.

### 5. Industrial Robotics & Pipeline Integrity (`Industrial_Robotics_Pipeline_Integrity.m`)

* **Методология:** Численное решение уравнения теплопроводности в частных производных (PDE, неявная схема Кранка — Николсона), прямая кинематика робототехники (Denavit-Hartenberg, 3-DOF).
* **Применение:** Термический анализ деградации стенок магистральных трубопроводов в паре с пространственным расчетом траектории диагностического сканирующего манипулятора.
